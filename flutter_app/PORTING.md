# Перенос сайта в приложение

Карта того, что уже работает в `flutter_app`, что осталось, и почему сделано именно так.
Источник истины по логике — `backend/main.py` (эндпоинты) и `frontend/app.js` (поведение).

Игры (дурак, шахматы, бильярд, UNO, 101) сознательно не переносятся.

---

## Что закрыто

### Кино — паритет с сайтом

| Вкладка | Эндпоинты | Файл |
|---|---|---|
| Дневник | `/watched`, `/watched/rate` | `screens/movies_screen.dart` |
| К просмотру | `/watchlist`, `PATCH /watchlist/{id}/category` | там же |
| Отклонённые | `/dismissed`, `/dismiss` | там же |
| Актёры | `/watched/top-actors`, `/favorite-actors`, `/person/{id}/watched-appearances`, `/person/{id}/movies`, `/search/person` | `screens/actors_screen.dart` |
| Рекомендации | `/recommendations`, `/genres`, `/studios`, `/studio/{id}/movies` | `screens/recommendations_screen.dart` |
| ✦ Посоветуй | `/ai/suggest` | `screens/ai_suggest_screen.dart` |
| Профиль | `/profile/stats`, `/profile/analyze` | `screens/profile_screen.dart` |

Карточка фильма (`movie_detail_screen.dart`) дополнена: тап по актёру открывает
его страницу, появилась кнопка «Больше не предлагать».

### Книги — паритет с сайтом

Открытие (`/books/popular`), Дневник, Хочу прочесть, ✦ Посоветуй (`/books/suggest`),
Профиль. Добавлен экран карточки книги (`/books/{id}/details`, `/books/{id}/similar`) —
раньше поиск молча клал книгу в список, посмотреть описание было негде.

Книжная статистика считается на клиенте: отдельного эндпоинта под неё у бэкенда нет,
а всё нужное уже лежит в списке прочитанного.

## Найденные и исправленные ошибки

1. **Поиск не работал ни в кино, ни в книгах.** Клиент слал `?query=`,
   а `/search` и `/books/search` ждут `?q=` — каждый запрос возвращал 422.
2. **`/ai/suggest` не возвращал ничего.** В `backend/main.py` функция досчитывала
   `results` и заканчивалась без `return` — FastAPI отдавал `null`, и вкладка
   «✦ Посоветуй» на сайте была пустой при любом запросе. Добавлен ответ
   `{"movies": [...], "debug_ai": [...]}` — ровно тот формат, который читает `app.js`.
3. **Гонка при загрузке книг.** `loadPopular()` использовал общий флаг синхронизации
   с личными списками: оба стартовали в одном кадре, второй отменялся, и подборка
   «Открытие» не появлялась до ручного обновления. Теперь у неё свой флаг.

## Что переработано в структуре

- **Навигация.** Раньше каждый раздел был одним плоским экраном с парой переключателей.
  Теперь `SubTabView` (`widgets/sub_tabs.dart`) повторяет вкладки сайта, и вкладки
  строятся лениво: пока не откроешь «Актёров», их дорогой запрос не уходит.
- **Общие детали вынесены** в `widgets/stats.dart` (графики профиля),
  `widgets/ai_panel.dart` (ожидание AI, объяснения, строка запроса).
  До этого таких блоков просто не было, и каждый экран рисовал бы их заново.
- **Модели разделены по смыслу.** У книги были склеены своя оценка и средняя
  по Google Books в одном поле `rating` — теперь это `rating` и `communityRating`.

## Что ещё не перенесено

Всё из режима «Тетрадь», кроме задач, списков, заметок, целей и базового бюджета:

- **Поездки** — `/trips` целиком: дни, заметки по дням, расходы, группировка.
- **Календарь** — месячная сетка и `/tasks/week`.
- **Бюджет** — импорт PDF-выписки (`/budget/parse-statement`, `/budget/import`),
  события (`/budget/events`), подсказки по мерчантам (`/budget/merchants`),
  очистка месяца, правка категорий.
- **Виш-лист** — отправка заявки в друзья (`POST /friends/request`);
  приём и отклонение уже работают.
- **Мелочи шапки** — глобальный поиск и переключение светлой темы.

## Как запускать

```bash
cd flutter_app
flutter pub get
flutter run --dart-define=API_BASE_URL=http://localhost:8000
```

Без `--dart-define` клиент идёт на боевой сервер из `core/config.dart`.
