# Сборка APK

Отдельное приложение для телефона — то, ради чего Flutter и брали.
Один и тот же код собирается в веб, Windows и Android.

На Android блокировка рекламы работает **полностью**, в отличие от веба:
там наш собственный WebView, а не чужой iframe в браузере, поэтому
и запросы отсекаются, и попапы, и подложки.

---

## Разово: проверить окружение

```powershell
flutter doctor
```

Нужны зелёные галочки у **Android toolchain**. Если ругается на лицензии:

```powershell
flutter doctor --android-licenses
```

и жать `y`, пока не кончатся. Android Studio ставить целиком не обязательно —
хватает Android SDK Command-line Tools.

---

## Собрать

```powershell
cd E:\movie-app\flutter_app
flutter build apk --release --split-per-abi
```

Готовые файлы лежат в:

```
build\app\outputs\flutter-apk\
```

Их будет три — под разные процессоры. На любой современный телефон нужен

```
app-arm64-v8a-release.apk
```

`--split-per-abi` даёт три файла примерно по 25 МБ вместо одного на 60.
Если лень разбираться, какой ставить, собери без этого флага — получится
один `app-release.apk`, который встанет куда угодно, просто потолще.

## Про адрес сервера

**Не передавай `--dart-define=API_BASE_URL=http://localhost:8000`.**
Для телефона `localhost` — это он сам, а не твой компьютер. Приложение
просто не увидит сеть.

По умолчанию (без флага) клиент идёт на боевой сервер из `core/config.dart` —
это то, что нужно.

Если хочешь на время разработки завернуть телефон на свой компьютер,
он должен быть в той же Wi-Fi сети, и адрес нужен настоящий:

```powershell
ipconfig    # найди IPv4-адрес, например 192.168.1.42
flutter build apk --release --dart-define=API_BASE_URL=http://192.168.1.42:8000
```

Плюс uvicorn надо запускать так, чтобы он слушал не только себя:

```powershell
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

## Поставить на телефон

Самое простое — подключить телефон кабелем, включить отладку по USB и:

```powershell
flutter install
```

Либо скинуть `.apk` в Telegram самому себе, открыть с телефона и разрешить
установку из неизвестных источников.

## Подпись

Сейчас релиз подписывается отладочным ключом (`build.gradle.kts`, блок
`buildTypes.release`). Для себя и друзей этого достаточно — приложение
ставится и работает.

Отдельный ключ понадобится, если захочешь выкладывать в Google Play или
обновлять приложение, не удаляя старое. Тогда:

```powershell
keytool -genkey -v -keystore %USERPROFILE%\monkey-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias monkey
```

и прописать его в `android/key.properties` + `build.gradle.kts`.
Скажи, если дойдём до этого, — настрою.

## Что ещё стоит сделать перед раздачей

- **Иконка.** Сейчас стандартный флаттеровский значок.
  Ставится пакетом `flutter_launcher_icons` из одной картинки.
- **Название.** Уже поправлено на «Monkey App» в `AndroidManifest.xml`.
- **Версия.** `version: 1.0.0+1` в `pubspec.yaml`; число после `+`
  надо увеличивать при каждом обновлении, иначе телефон посчитает
  новую сборку той же самой.
